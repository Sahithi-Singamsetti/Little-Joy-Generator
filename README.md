# 🐰 Little Joy

*A tiny corner of the internet for softer days. ♡*

Little Joy is a cozy, pastel-themed self-care app built with Python and Streamlit. It's designed to bring a little comfort, encouragement, and joy into everyday life.

## 🌷 Features

- ☀️ **Little Joy** — Find a little moment of happiness.
- 📔 **Mood Diary** — Reflect on your feelings and track your moods.
- 🫙 **Gratitude Jar** — Collect little things you're grateful for and revisit the moments that make life special.
- 🫧 **Breathing Buddy** — Take a mindful breathing break.
- 🌷 **Affirmations** — Gentle reminders for difficult days.
- 🎧 **Music Corner** — Discover music for different moods.
- ♡ **My Collection** — Keep track of your favourites.
- 🍓 **Tiny Adventures** — Try small activities to brighten your day.

## 🛠️ Built With

- Python
- Streamlit
- Pandas

## 💻 Run Locally

1. Clone this repository.
2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the app:

   ```bash
   streamlit run app.py
   ```

4. Open the local URL shown in your terminal.

## 💗 A Little Note

Little Joy was created as a reminder that happiness doesn't always have to come from big things. Sometimes, it's the smallest moments that make a day feel special.

Take a breath. Be gentle with yourself. Find your little joy. ✨
